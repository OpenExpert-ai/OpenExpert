# 12 · Modelo de licencia

> **Audiencia:** ambos.

---

## 1. Licencia

Todo el repositorio se distribuye bajo la **Licencia MIT**
([`LICENSE`](../../LICENSE)). Incluye la aplicación, el paquete `opencore`, la
configuración de Docker y la documentación.

## 2. Sin nube alojada

OpenExpert es solo local. No hay edición alojada, ni proyecto Supabase, ni
despliegue en Vercel. Lo ejecutas en tu propio equipo.

## 3. Monetización

Como el código es totalmente abierto y se ejecuta en local, la monetización no
se basa en el software. Si en el futuro existe una oferta de pago, sería un
servicio alrededor del proyecto (soporte, builds empaquetados), nunca una
restricción sobre el código.

## 4. Obligaciones

MIT es permisiva: conserva el aviso de copyright y el de permiso en las copias
del software. Los componentes de terceros mantienen sus licencias (ver
[`NOTICE`](../../NOTICE)). No uses la marca OpenExpert de forma que sugiera
respaldo.

## 5. Contribuir

Al contribuir aceptas el Developer Certificate of Origin 1.1
([`CONTRIBUTING.md`](../../CONTRIBUTING.md)) y tu contribución se publica bajo
MIT.

## 6. Reportes de seguridad

Reporta vulnerabilidades de forma privada — ver [`SECURITY.md`](../../SECURITY.md).
